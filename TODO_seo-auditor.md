## 1. Discovery and Crawl Analysis

- [ ] **SEO-FIND-1.1 Legacy Static Sitemap Conflict**:
  - **Location**: `/public/sitemap.xml`
  - **Description**: An outdated static sitemap exists in `/public/sitemap.xml` containing legacy staging URLs (`https://constructora-rodriguez-javier.pages.dev/*.html`) and obsolete query parameter routes (`proyecto.html?id=fallback-1`), conflicting directly with the dynamically generated `@astrojs/sitemap` index at `/sitemap-index.xml`. Search engines crawling `/sitemap.xml` encounter legacy domains, causing canonical confusion and indexing errors in Google Search Console.
  - **Impact**: High
  - **Recommendation**: Remove or redirect `/public/sitemap.xml` so that search engines solely consume `/sitemap-index.xml` pointing to `https://www.rodriguezjaviers.com/`.

- [ ] **SEO-FIND-1.2 Unprotected & Indexable Admin Route in Sitemap**:
  - **Location**: `/src/pages/admin/index.astro` (`/admin`)
  - **Description**: The administrative dashboard at `/admin` has no `noindex, nofollow` robots meta tag. It is generated by Astro as a static route, meaning it can be indexed by Google and appear in search results, diluting domain authority and exposing the internal CMS login.
  - **Impact**: Critical
  - **Recommendation**: Add `<meta name="robots" content="noindex, nofollow" />` to `/admin/index.astro` and explicitly disallow `/admin` in `/public/robots.txt`.

- [ ] **SEO-FIND-1.3 Legacy Single Dynamic Route vs Static Prerendered Route Cannibalization**:
  - **Location**: `/src/pages/proyecto.astro` vs `/src/pages/proyecto/[id].astro`
  - **Description**: Both `/proyecto.astro` (client-side query param based: `/proyecto?id=...`) and `/proyecto/[id].astro` (clean static prerendered path: `/proyecto/residencial-duran`) exist. The root `/proyecto` renders a blank placeholder or generic title `"Detalle de Propiedad"` without specific metadata, wasting crawl budget and creating duplicate thin content.
  - **Impact**: High
  - **Recommendation**: Redirect `/proyecto` to `/properties` via 301, or add a canonical tag pointing to `/properties`. Ensure all internal links exclusively use canonical slug paths `/proyecto/[id]`.

- [ ] **SEO-FIND-1.4 Robots.txt Crawl Directives Omission**:
  - **Location**: `/public/robots.txt`
  - **Description**: Current `robots.txt` only has `Allow: /` for `*` and `AdsBot-Google`. It lacks explicit rules disallowing `/admin` or staging environments, and does not specify explicit directives for AI crawlers (GPTBot, PerplexityBot, ClaudeBot, Google-Extended) to optimize answer engine indexation.
  - **Impact**: Medium
  - **Recommendation**: Modernize `robots.txt` with disallow rules for `/admin` and clean access rules for search engines and generative answer engines.

## 2. Technical Health Assessment & Core Web Vitals

- [ ] **SEO-FIND-2.1 Client-Side Rendered Language Flash & Content Indexation**:
  - **Location**: `/public/js/lang.js` and `/src/layouts/Layout.astro`
  - **Description**: Translation into English, French, and Creole is performed 100% via client-side DOM replacement (`data-i18n`). Googlebot parses HTML first; crawlers that do not execute JavaScript or answer engine scrapers (like Perplexity or ChatGPT bot) only see Spanish content. Furthermore, there are no separate language URLs (`/en/`, `/fr/`) or `hreflang` alternate tags.
  - **Impact**: Critical
  - **Recommendation**: Implement `hreflang` annotations declaring `es` as default, or configure subpath/subdomain internationalization. For AEO queries in English (e.g., "buy luxury villa Dominican Republic"), search engines must be provided server-rendered localized metadata and alternate hreflang links.

- [ ] **SEO-FIND-2.2 Render-Blocking Google Fonts & Web Font Optimization**:
  - **Location**: `/src/layouts/Layout.astro` (lines 79–81)
  - **Description**: Fonts (*Cormorant Garamond*, *Inter*, *Playfair Display*) are loaded via standard synchronous `<link>` stylesheet tags from Google Fonts without `font-display: swap` explicitly forced across all weights, contributing to TTFB and LCP latency.
  - **Impact**: Medium
  - **Recommendation**: Preload font files or apply `&display=swap` alongside local font bundling with `@fontsource` to ensure 0ms layout shift (CLS < 0.05) and instant text rendering.

- [ ] **SEO-FIND-2.3 Hardcoded Staging Image Fallback in Property Layout**:
  - **Location**: `/src/pages/proyecto/[id].astro` (line 18)
  - **Description**: The fallback OpenGraph and schema image references a temporary staging domain: `https://e0a90387.constructora-rodriguez-javier.pages.dev/assets/images/hero/hero-bg.webp`.
  - **Impact**: Medium
  - **Recommendation**: Replace all instances of `pages.dev` URLs with the canonical production domain `https://www.rodriguezjaviers.com`.

- [ ] **SEO-FIND-2.4 Missing Custom 404 Error Page**:
  - **Location**: `/src/pages/404.astro`
  - **Description**: There is no custom `404.astro` page in the project. Broken URLs or expired project links result in Cloudflare's generic error page, creating user bounce and dropping crawl equity.
  - **Impact**: Medium
  - **Recommendation**: Build a branded luxury `404.astro` with navigation back to `/properties` and search/contact triggers.
